# DronexMC Network Applications

موقع تقديمات ثنائي اللغة (عربي/إنجليزي) لفريق DronexMC: Next.js 14 (App Router) + TypeScript + Tailwind + Supabase + Discord OAuth2. للإعداد والنشر راجع **DEPLOY.md**.

## ما تم تنفيذه (كتابة الكود)
- دخول Discord (`identify` فقط، تحقق `state`، جلسة HttpOnly) على مسار واحد `/callback`.
- صفحة رئيسية ببطاقات النماذج من قاعدة البيانات، ثيم داكن/فاتح، RTL/LTR محفوظان في Cookie.
- نماذج افتراضية (20/20/15 سؤالًا) بالعربية والإنجليزية، وتقديم مع مراجعة ومسودة محلية ورقم تقديم فريد ومنع تكرار على مستوى قاعدة البيانات.
- حالات الطلب ورسائلها للمتقدم (قيد المراجعة/مقبول/مرفوض).
- لوحة إدارة: دخول bcrypt مع إجبار تغيير `admin/admin`، إحصائيات، بحث وتصفية، تغيير الحالة، حذف بتأكيد، إعدادات الموقع، سجل عمليات.
- منشئ نماذج وأسئلة (10 أنواع) مع مسودات ونسخ ثابتة (Versioning) ومعاينة.
- Discord Webhooks لكل نموذج مع تقسيم الرسائل، إعادة محاولة (Cron + يدوي)، اختبار، وسجل.
- صفحتا Terms وPrivacy، وسياسات RLS تقفل الجداول أمام المتصفح.

## حالة الاختبار — اقرأها
- **لم يُشغَّل** `npm install` ولا `build` ولا الاختبارات في بيئة الكتابة (بلا إنترنت). لا ضمان أن البناء ينجح من أول مرة.
- لم تُختبر فعليًا: Discord OAuth، Supabase، Webhooks (تحتاج بياناتك).
- الاختبارات الموجودة (Vitest): تحقق الإجابات وتحقق مخطط الأسئلة فقط. ليس هناك اختبارات تكامل لمنع التكرار أو الصلاحيات.

## حدود معروفة
- لا رفع ملفات.  ESLint غير مضبوط.
- تحديد المحاولات مطبّق على دخول الإدارة فقط (ليس على الإرسال أو بقية الواجهات).
- الـ Cron يومي (حد الخطة المجانية)؛ الإرسال الفوري والإعادة اليدوية يعملان فورًا.
- أيقونة النموذج تُحفظ لكن لا تُعرض في البطاقة؛ نصوص الشروط والخصوصية مختصرة وتحتاج مراجعتك.
- تغيير الإدارة لا يدعم عدة مسؤولين (حساب واحد).

## التشغيل المحلي
```
npm install && cp .env.example .env.local   # عدّل القيم
npm run dev
```
